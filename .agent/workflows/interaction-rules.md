# Interaction Rules

To streamline our development process, please follow these rules unless explicitly instructed otherwise:

1. **Browser Verification**: You do not have to check with a browser subagent/preview after every change you make. Only do so when specifically requested or if a visual verification is critical for a complex UI change.
2. **GitHub Backups**: You do not have to backup or commit to GitHub after every change. Wait for an explicit request to commit or push changes.
3. **Major Changes**: Do not execute code that results in major structural changes (like deleting files, significant refactoring, or merging multiple components) without first affirming the plan with the user and getting approval.
